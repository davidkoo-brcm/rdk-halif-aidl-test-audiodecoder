# AudioDecoder HAL Test Suite

This repository contains the Vendor Test Suite (VTS) for the `IAudioDecoder` AIDL HAL interface. It is designed to validate the functionality of the AudioDecoder HAL implementation.

## Build Steps

This test suite is part of Unified VTS for AIDL HALs. For initial setup, environment configuration, and build instructions, please refer to the Unified VTS README documentation.

- **[Unified VTS README](https://github.com/rdkcentral/rdk-halif-aidl-unified-vts/blob/main/README.md)**

## Running the AudioDecoder Tests

While the Unified VTS can run all tests at once, you can execute the `VTS_L1_AudioDecoder` and `VTS_L3_AudioDecoder` test suite individually for targeted validation. This is useful for debugging and development of the `AudioDecoder` HAL.
